Mapping flow

  1. Scan factory USN barcode on the unit.
  2. Backend → Unicommerce → SKU / product card.
  3. Scan RFID on the physical unit.
  4. If USN or RFID already mapped → block.
  5. Else save USN ↔ RFID (+ SKU from Unicommerce) + audit.
